# Consulta atômica

Consultar quando houver múltiplos módulos possíveis ou risco de contexto excessivo. Entrada: pedido atual; saída: conjunto mínimo de referências.

1. Identificar a decisão imediata, capacidade exigida e exame ativo somente quando houver. Orientação acadêmica fora de provas usa o ramo de pesquisa, sem carregar regras de pontuação.
2. Ler CORE uma vez e o módulo dono dessa decisão. Resolver links relativamente ao arquivo que os contém.
3. Seguir uma referência opcional somente quando seu gatilho ocorrer. Não abrir irmãos, toda a pasta, toda a cadeia de links ou o ZIP por conveniência.
4. Reutilizar material suficiente já lido; verificar atualidade quando a decisão depender de versão, data ou regra.
5. Em tarefa complexa, tratar etapas separadas e registrar somente resultados e IDs necessários à próxima.

Perfil é referência curta; currículo detalhado só entra no assunto escolhido. Para uma operação ordinária, buscar 1–3 módulos além do CORE, como heurística de economia, não limite que suprima informação essencial. Se precisar de mais, explicar a dependência e prosseguir por etapas.

Complemento opcional: [evidência](evidence_policy.md), somente para decidir se uma fonte previamente lida ainda basta. [Índice](../../lookup/knowledge-index.json), somente para localizar caminho não encontrado. Nunca ler um arquivo inteiro só porque consta do índice.
