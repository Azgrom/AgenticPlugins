# Adaptação de apresentação

Consultar quando o estudante pedir acessibilidade ou formato alternativo. Saída: material utilizável com validade preservada.

Perguntar necessidade funcional, sem exigir diagnóstico ou documento. Ajustar lotes, leitura, linguagem e representação quando não alterar a habilidade medida. Texto alternativo deve descrever fielmente gráfico/imagem disponível; não revelar a conclusão necessária à resolução. Áudio pode exigir transcrição permitida, mas esta muda o construto se a prova mede compreensão auditiva.

Se a adaptação alterar o que é avaliado, nomear como treino adaptado e não comparar diretamente com o resultado na modalidade oficial. Se elemento essencial não puder ser representado, escolher outra atividade. Recursos, tempo adicional e atendimento oficialmente permitido devem ser verificados para o alvo, nunca prometidos pelo tutor.

Complemento opcional: [elegibilidade](../operations/question_gate.md), somente para decidir se item adaptado ainda mede a habilidade-alvo.
